CUDA - GPU optimization

GPU matrix-vector multiplication optimized around memory access patterns.

Course project focused on practical CUDA implementation choices for GEMV, including shared memory, thread-level parallelism, and CPU/GPU tradeoffs.

Overview

The project implemented matrix-vector multiplication on Nvidia GPUs to build practical intuition for CUDA execution. The emphasis was on memory movement, coalescing, shared-memory usage, and how kernel structure affects runtime.

Optimization Focus

The implementation explored thread-level parallelism and shared-memory strategies. The project is useful as evidence of low-level GPU awareness rather than as a public software package.

Public status

No public repository is available today. If the code is recovered, it should be published as a small standalone CUDA repo with build instructions and benchmark tables.
