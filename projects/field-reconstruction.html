Cardiac signal-field reconstruction from sparse measurements.

CNN encoder-decoder approach for reconstructing scalar fields in cardiac electrophysiology from 20 known points. The repository remains private because the work is research/manuscript material.

Overview

The project studies how neural models can reconstruct spatial signal fields from sparse observations. The core system uses a custom CNN encoder-decoder trained to infer full cardiac signal fields from a small set of known measurement points.

Method

The work involved designing the model and training setup from scratch, preparing field data, evaluating reconstruction quality, and building early 1D signal-processing steps to identify the timing of relevant events in recorded signals.

Public status

The code and data are not public at this stage. Public claims are limited to the method, task, and manuscript-in-preparation status.
